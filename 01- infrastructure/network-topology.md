# Network Topology

Documentation of the virtual network architecture
used in the Sebbeco Enterprise Home Lab.

## Network Configuration

| Device | Hostname | IP Address |
|---|---|---|
| Domain Controller | DC01 | 192.168.10.10 |
| Client Workstation | CLIENT01 | 192.168.10.20 |


## Purpose
The lab uses an isolated virtual network (host-only network type) to simulate a small enterprise environment. The domain controller provides Active Directory and DNS services to domain-connected client machines.
